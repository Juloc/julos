# JulOS 0.4.0-beta.29

Released 2026-09-02.

## Summary

Twenty-ninth JulOS beta. Three navigation features: an iPadOS-style auto-hiding dock with home-indicator gestures on mobile, mobile app-switching by swipe, and a keyboard command palette on desktop. Frontend-only; the server image is rebuilt to carry the new Desktop bundle. No package, runtime or provider images change.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.28` |

Pull the new server image and redeploy. Hard-refresh the browser (or reopen the installed PWA) once so the updated shell assets load.

## Changed

- **Auto-hiding dock (mobile).** When an application fills the screen the shell enters immersive mode: the dock slides away, the app goes edge-to-edge, and a home indicator appears at the bottom. On the home screen (no app open) the dock stays visible and content clears it as before.
- **Home-indicator gestures (mobile).** Swipe up on the home indicator — or tap it — to reveal the dock as an overlay; it auto-hides again after a few seconds. Swipe left or right to switch between open applications. Gestures are pointer-based, so they respond to both touch and mouse.
- **Keyboard command palette (desktop).** `Ctrl`/`Cmd`+`K` now opens the launcher with the search field focused and cleared, so you can type to find an application and press Enter to open the top match. This builds on the launcher search added in `0.4.0-beta.28`.

## Known limitations

- The mobile home-indicator gestures share the bottom screen edge with the operating system's own gestures; installing JulOS as a PWA gives them the most room. Fine-tuning against real devices is ongoing.
- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
