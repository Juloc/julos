# JulOS 0.4.0-beta.41

Released 2026-09-05.

## Summary

Forty-first JulOS beta. Fixes Browser subresources that use CORS fetch modes without cookies and
adds a safe fallback for stale index-document navigation.

## Fixed

- Rewritten Browser subresources now carry short-lived Data-Protection-signed capabilities bound
  to the encoded JulOS target host.
- Cookie-less GET/HEAD subresource requests can use those capabilities without opening the proxy to
  unauthenticated arbitrary traffic.
- Capability query parameters are removed before forwarding to the upstream.
- Cross-origin fonts and similar resources can now reach the upstream so Origin/Referer
  virtualization and CORS response mapping can take effect.
- If a Browser navigation requests an index document that returns 404, JulOS retries the containing
  directory root once. This covers sites where a stale `/index.html` URL should resolve to the
  actual root application.
- Existing redirect handling, new-tab proxying, Browser URL synchronization and HTML/CSS rewriting
  remain in place.
- Added regression coverage for valid/invalid subresource capabilities and missing-index fallback.
