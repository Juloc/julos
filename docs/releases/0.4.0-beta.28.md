# JulOS 0.4.0-beta.28

Released 2026-09-01.

## Summary

Twenty-eighth JulOS beta. It activates launcher search: the launcher already had a permission-filtered, ranked search index and a runtime search method, but no input to drive them. A search field is added to the launcher so applications are findable by name instead of only by scrolling — especially useful on mobile, where the launcher is the primary way in. Frontend-only; the server image is rebuilt to carry the new Desktop bundle. No package, runtime or provider images change.

Pull the new server image and redeploy. Hard-refresh the browser (or reopen the installed PWA) once so the updated shell assets load.

## Changed

- **Launcher search is now usable.** A localized "Search and commands" field sits at the top of the launcher and filters entries as you type; Enter opens the top match. It is wired to the existing ranked, permission-aware search index, so results are ordered by relevance and never show applications the user cannot launch. The query resets whenever the launcher opens or closes, and the desktop search button focuses the field. The field uses a 16px font so mobile Safari does not auto-zoom on focus.

## Known limitations

- Launcher search matches application titles, ids and keywords; it does not yet search inside installed applications or run arbitrary commands.
- The mobile dock is always visible (it does not overlap content, but does not yet auto-hide per-app the way iPadOS does).
- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
