# JulOS 0.4.0-beta.1

First JulOS beta focused on directly testable desktop applications.

## Included

- Browser URLs can be saved as JulOS launch targets and started directly from the Desktop launcher.
- Browser sessions render the real isolated Chromium display inside the JulOS window through the existing interactive-session and Remote display contracts.
- Browser display input supports keyboard, mouse, touch and dynamic resizing.
- Launch targets use the existing Core `launch_targets` persistence model; no second favorites or shortcut store was added.
- The Desktop ships the pinned Apache Guacamole 1.6.0 browser client as a same-origin, SHA-256-verified build asset.
- Existing package, capability and Runtime Manager boundaries remain unchanged.

## Remote status

- SSH has already been exercised end to end in the current Remote implementation.
- RDP and VNC code paths are present but remain experimental in beta.1 because the standalone Remote provider / Runtime Manager deployment is not yet part of the simple beta compose.

## Deployment

Use the release compose and environment example attached to this prerelease. The beta server image is:

`ghcr.io/juloc/julos-server:0.4.0-beta.1`

Browser execution additionally requires the Browser package to be installed/enabled and configured with a digest-pinned Browser Runtime image and an allowed/default Docker network.
