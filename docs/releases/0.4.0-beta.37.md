# JulOS 0.4.0-beta.37

Released 2026-09-05.

## Summary

Thirty-seventh JulOS beta. Prevents Browser proxy redirect loops caused by permanent redirects
cached against encoded JulOS proxy hosts.

## Fixed

- Upstream `301` redirects are exposed to the Browser as temporary `302` redirects.
- Upstream `308` redirects are exposed as temporary `307` redirects.
- Redirect responses are marked `Cache-Control: no-store` and `Pragma: no-cache` at the JulOS
  proxy boundary.
- Existing redirect URL rewriting, iframe navigation metadata normalization and sanitized redirect
  diagnostics remain in place.
- Added regression coverage proving permanent upstream redirects cannot become permanent JulOS
  proxy-host cache entries.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.36` |
| Database migration required | no |
| Downtime expected | brief restart |
| Safe mode required | no |

After upgrading, a browser that already cached an older permanent redirect for an encoded proxy
host may need its site data/cache cleared once, or the same test can be confirmed in a private
window.
