# JulOS 0.4.0-beta.36

Released 2026-09-05.

## Summary

Thirty-sixth JulOS beta. Improves Browser proxy navigation compatibility for sites that react to
iframe Fetch Metadata or emit relative/canonical redirects.

## Fixed

- Browser iframe navigations are presented upstream as ordinary top-level document navigations
  instead of leaking `Sec-Fetch-Dest: iframe`.
- Inbound JulOS `Sec-Fetch-*` navigation metadata is normalized before forwarding.
- Relative, scheme-relative and absolute HTTP(S) redirect targets are resolved against the actual
  upstream request URI and rewritten back into the JulOS proxy.
- Sanitized redirect diagnostics record status plus source/target paths without query or fragment
  values, so remaining redirect loops can be identified safely.
- Existing HTTPS-behind-Caddy handling and dynamic-target forwarding-header isolation remain intact.
