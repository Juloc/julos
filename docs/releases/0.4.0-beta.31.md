# JulOS 0.4.0-beta.31

Released 2026-09-02.

## Summary

Thirty-first JulOS beta. It fixes the mobile home-indicator gestures introduced in `0.4.0-beta.29`, which did not fire on real touch devices — leaving the auto-hidden dock unreachable. Frontend-only; the server image is rebuilt to carry the new Desktop bundle. No package, runtime or provider images change.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.30` |
| Database migration required | no |
| Downtime expected | brief restart |
| Safe mode required | no |

Pull the new server image and redeploy. Hard-refresh the browser (or reopen the installed PWA) once so the updated shell assets load.

## Fixed

- **Mobile home-indicator gestures now work on touch.** A swipe lifts the finger up into the app content, away from the small indicator, but the handler listened for the pointer release *on the indicator* — so the swipe was lost and the auto-hidden dock stayed hidden and unreachable. The whole gesture is now tracked at the window level: it starts on the indicator and completes wherever the finger lifts. A tap on the indicator remains a reliable way to bring the dock back. The indicator hit area is also larger.

## Changed

- Nested scroll panes get momentum scrolling on iOS (`-webkit-overflow-scrolling: touch`).

## Known limitations

- Local Web renders internal apps in a sandboxed iframe and does not bypass CSP or `X-Frame-Options`; apps that forbid framing stay blank. A fallback that hands such apps to the Adaptive Browser's server-rendering mode is planned.
- The mobile home-indicator gestures share the bottom screen edge with the operating system's own gestures; installing JulOS as a PWA gives them the most room.
- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
