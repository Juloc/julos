# JulOS 0.4.0-beta.30

Released 2026-09-02.

## Summary

Thirtieth JulOS beta. It completes the command palette from `0.4.0-beta.29`: launcher search results are now keyboard-navigable. Frontend-only; the server image is rebuilt to carry the new Desktop bundle. No package, runtime or provider images change.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.29` |
| Database migration required | no |
| Downtime expected | brief restart |
| Safe mode required | no |

Pull the new server image and redeploy. Hard-refresh the browser (or reopen the installed PWA) once so the updated shell assets load.

## Changed

- **Keyboard-navigable command palette.** After opening the launcher with `Ctrl`/`Cmd`+`K` and typing, `ArrowDown`/`ArrowUp` now move an accent-highlighted selection through the results (wrapping at both ends), and `Enter` opens the selected entry rather than always the first match. The selection resets to the top result on each keystroke and whenever the launcher opens.

## Known limitations

- The command palette searches application titles, ids and keywords; it does not yet search inside installed applications or run arbitrary commands.
- The mobile home-indicator gestures share the bottom screen edge with the operating system's own gestures; installing JulOS as a PWA gives them the most room.
- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
