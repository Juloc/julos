# JulOS 0.3.0-alpha.5

Release date: 2026-08-07

This alpha fixes the SQLite Remote lifecycle failure found during real `0.3.0-alpha.4` deployment and hardens upgrades of existing Docker volumes.

## Fixed

- SQLite maps UTC `DateTimeOffset` persistence values through provider-side UTC `DateTime`, allowing EF Core to translate Remote session deadline comparisons and ordering fully to SQL;
- the Remote lifecycle worker no longer fails every reconciliation pass with an untranslatable LINQ expression;
- a SQLite regression test executes the affected comparison and ordering query shape server-side;
- the server entrypoint repairs ownership of existing root-owned persistent directories before dropping to the non-root runtime user;
- the release smoke test reproduces an upgrade from an older root-owned Docker volume and verifies the repaired ownership;
- the SQLite health check executes as the JulOS runtime user instead of bypassing the entrypoint as root;
- both released alpha Compose variants reference the same `0.3.0-alpha.5` server image.

## Upgrade from alpha.4

No Core schema change is introduced by this release. Keep the existing `JULOS_PRIMARY_KEY` and persistent volume, pull `ghcr.io/juloc/julos-server:0.3.0-alpha.5`, and recreate the server container.

The startup entrypoint repairs the known older-volume ownership state automatically. Manual database edits or volume recreation are not required.

## Docker evaluation

The recommended evaluation deployment remains `deploy/alpha/compose.sqlite.yaml`. It runs one JulOS server container, requires no PostgreSQL service and persists its state in one named volume.

Required environment value:

- `JULOS_PRIMARY_KEY`: generate with `openssl rand -base64 32`.

The release Compose file binds to `127.0.0.1:8080` by default. The `Juloc/docker` deployment uses host port `18199`.

SQLite is intended for one JulOS server replica. PostgreSQL remains available for deployments that require it.

## Released component

- `ghcr.io/juloc/julos-server:0.3.0-alpha.5`

Browser Runtime and Remote Transport are unchanged from their previously published alpha artifacts.
