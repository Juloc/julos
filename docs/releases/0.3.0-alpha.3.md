# JulOS 0.3.0-alpha.3

Release date: 2026-08-07

This alpha makes the lightweight single-service Docker deployment the supported evaluation path and completes the Browser runtime fixes found by real lifecycle testing.

## Fixed

- Browser Runtime health checks now use the same `/tmp/julos-browser` state directory as the launcher;
- Openbox starts through the container `DISPLAY` environment instead of an unsupported command-line option;
- Browser Runtime diagnostics expose the Xvfb, Openbox, x11vnc and Chromium logs on smoke-test failure;
- SQLite package storage can run normal process package workers instead of disabling all workers;
- PostgreSQL package workers retain their restricted per-package role and schema behavior;
- Server, Browser Runtime and Remote Transport publication workflows now publish from `main`.

## Docker evaluation

The recommended alpha deployment is the single-service SQLite Compose stack. It runs only the JulOS server container, persists Core data, package data and protected key material in one named volume, and does not require PostgreSQL.

Required environment value:

- `JULOS_PRIMARY_KEY`: generate with `openssl rand -base64 32`.

The default endpoint of the release Compose file is `http://127.0.0.1:8080`. The `Juloc/docker` deployment binds JulOS to host port `18199`.

SQLite is intended for a single JulOS server replica. PostgreSQL remains available for deployments that need it.

## Released components

- `ghcr.io/juloc/julos-server:0.3.0-alpha.3`
- `ghcr.io/juloc/julos-browser-runtime:0.3.0-alpha.3`
- `JulOS.Remote.Transport` `0.3.0-alpha.3`

The Browser Runtime remains an internal runtime managed by JulOS rather than a separately exposed application port.
