# JulOS 0.4.0-beta.25

Released 2026-08-31.

## Summary

Twenty-fifth JulOS beta. It fixes Adaptive Browser server-rendering mode, which started the browser and then failed with "Adaptive Browser session response is invalid." The Adaptive Browser package is updated to `0.1.1`; the server image is rebuilt to carry the corrected catalog. The runtime and provider images are unchanged.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.24` |
| Database migration required | no |
| Downtime expected | brief restart |
| Safe mode required | no |

Pull the new server image and redeploy. Then update the installed **Adaptive Browser** package to `0.1.1` in the JulOS package catalog. Deployments that enabled Adaptive Browser server mode must also set the Remote provider `PackageVersion` to `0.1.1` (see the stack README).

## Fixed

- **Adaptive Browser server mode failed with "session response is invalid" after the browser started.** The frontend validated the interactive-session response identifier against a UUIDv1–5 pattern, but JulOS issues UUIDv7 session identifiers, so every real server-mode session was rejected once it was created. The frontend now accepts UUIDv1–7; its test used a v4 identifier and so never caught this. Shipped as Adaptive Browser `0.1.1`.

## Changed

- The server image is rebuilt at beta.25 with the Adaptive Browser `0.1.1` package embedded in the official catalog. Runtime Manager (`0.4.0-beta.17`), the Remote Provider, the Browser Runtime and the Adaptive Browser runtime and provider images are unchanged.

## Known limitations

- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
