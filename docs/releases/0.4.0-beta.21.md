# JulOS 0.4.0-beta.21

Released 2026-08-26.

## Summary

Twenty-first JulOS beta. It fixes a package-uninstall defect found by driving the full package lifecycle against a running server: removing an installed package with data deletion did not release the package's pooled SQLite connection before deleting the database file. Only the server image is rebuilt; the official packages stay at `1.0.4` and the runtime images are unchanged.

## Fixed

- **Uninstalling a package with data deletion could fail or leak its database handle.** The isolated package SQLite database is opened with connection pooling (`Cache=Shared`), so a pooled connection keeps the file open after every connection is disposed. Removal deleted the database files without clearing that pool. On Windows the open handle made the delete throw and the uninstall returned 500; on Linux the delete succeeded but the pool kept a handle to the now-unlinked file, so reinstalling the same package could be handed the stale pooled connection instead of the freshly created database. Removal now clears the pool for the package database before deleting its files. Verified end to end against a real signed package on a running host: install → enable → disable → uninstall returns 200 and the package and its data are gone.
