# JulOS 0.4.0-beta.18

Released 2026-08-23.

## Summary

Eighteenth JulOS beta. It ships the Browser runtime startup-grace fix that landed after beta.17's Browser runtime image was built: the isolated Chromium runtime now honours its startup grace period instead of self-terminating under heavy host load. The official packages are unchanged at `1.0.4`; only the server image and the digest-pinned Browser runtime image are rebuilt, and the official package catalog default points at the new Browser runtime digest.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.17` |
| Database migration required | no |
| Migration reversible | n/a |
| Downtime expected | brief restart |
| Safe mode required | no |

The official packages remain at `1.0.4`; no package update is required. The Browser runtime image is republished with a new digest, and the official catalog's Browser `runtimeImage` default points to it, so a fresh Browser package install picks it up automatically. An already-installed Browser package keeps its previously configured runtime image until it is reconfigured to the new digest.

## Fixed

- The Browser runtime honours its startup grace period instead of self-terminating ("VNC display endpoint did not become ready", exit 70) when it misses the 30-second grace under heavy host load.

## Changed

- The server image and the digest-pinned Browser runtime image are rebuilt at beta.18; the official package catalog's Browser `runtimeImage` default references the new Browser runtime digest.

## Known limitations

- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
