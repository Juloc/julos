# JulOS 0.4.0-beta.35

Released 2026-09-05.

## Summary

Thirty-fifth JulOS beta. Removes the final legacy synthetic WebApp launcher/iframe path and fixes
dynamic Browser proxy forwarding metadata that could cause redirect loops on public websites.

## Fixed

- Configured/static web targets are no longer synthesized as separate Desktop applications.
- The old Desktop WebApp iframe path and its sandbox configuration are removed completely.
- The Core Browser is now the only user-facing web browsing surface.
- Dynamic Browser targets receive their real upstream Host but no JulOS
  `X-Forwarded-Host`/`X-Forwarded-Proto` headers.
- The Browser still uses the public request scheme internally for JulOS redirect rewriting and
  cookie security, so HTTPS behind Caddy remains correct.
- Added regression coverage proving inbound `X-Forwarded-Proto: https` is used by JulOS but is not
  leaked to a dynamic/public upstream.
