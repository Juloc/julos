# JulOS 0.4.0-beta.40

Released 2026-09-05.

## Summary

Fortieth JulOS beta. Improves Browser rendering, URL fidelity, cross-origin resources and proxied
new-tab navigation.

## Fixed

- Browser iframe now reliably fills the remaining application window instead of collapsing to its
  intrinsic height.
- Proxied HTML reports its real upstream URL back to the JulOS address bar, including redirects and
  History API changes.
- Absolute HTTP(S) navigation/resource URLs in proxied HTML and CSS are rewritten into encoded
  JulOS proxy hosts, including common font/CDN references.
- `target=_blank`, popup and `window.open` HTTP(S) navigation is kept inside the JulOS proxy.
- Encoded Browser `Origin` and `Referer` request headers are virtualized back to their real
  upstream origins; matching `Access-Control-Allow-Origin` values are mapped back to the encoded
  Browser origin.
- Internal redirect collapsing is now limited to directory-index canonicalization such as
  `/index.html -> /`. Ordinary redirects such as `/ -> /Default.asp` remain browser-visible so
  the final document URL is correct.
- CSP is preserved while authorizing only the injected JulOS Browser bridge by its SHA-256 hash.
- Added regression coverage for AERA-style redirects, CORS origin virtualization, HTML/CSS URL
  rewriting and Browser URL synchronization.
