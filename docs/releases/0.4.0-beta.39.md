# JulOS 0.4.0-beta.39

Released 2026-09-05.

## Summary

Thirty-ninth JulOS beta. Prevents Browser canonical-path redirect loops by resolving safe
same-origin document redirects inside the proxy.

## Fixed

- Cookie-free same-origin GET/HEAD browser-navigation redirects are followed inside JulOS instead
  of being bounced back to the iframe.
- Internal navigation redirects are bounded to five hops and repeated targets fail explicitly with
  `508 webapp.redirect_loop`.
- Cross-origin redirects remain client-visible so JulOS can switch to the encoded host for the new
  origin.
- Redirects that set cookies remain client-visible, preserving normal browser cookie/redirect
  semantics.
- Existing redirect rewriting, HTTPS-behind-Caddy handling, cache protection and redirect
  diagnostics remain in place.
- Added regression tests for successful internal canonical redirects, loop detection and
  cookie-setting redirect preservation.
