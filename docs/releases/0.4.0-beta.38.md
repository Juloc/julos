# JulOS 0.4.0-beta.38

Released 2026-09-05.

## Summary

Thirty-eighth JulOS beta. Makes encoded Browser proxy redirect caches self-healing and improves
redirect diagnostics.

## Fixed

- Permanent upstream redirects still become temporary 302/307 responses at the proxy boundary.
- Permanent upstream redirects now also send `Clear-Site-Data: "cache"` for the encoded JulOS
  proxy origin, clearing stale cached redirects without deleting site cookies or storage.
- JulOS now logs the final rewritten status and sanitized `Location` value actually returned to
  the browser, in addition to the upstream redirect.
- Existing redirect rewriting, HTTPS-behind-Caddy handling and iframe navigation metadata
  normalization remain unchanged.
- Regression coverage verifies the cache-clearing response header on permanent redirects.
