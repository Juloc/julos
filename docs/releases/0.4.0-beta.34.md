# JulOS 0.4.0-beta.34

Released 2026-09-05.

## Summary

Thirty-fourth JulOS beta. Fixes Browser mixed-content redirects when JulOS runs behind an HTTPS
reverse proxy such as Caddy, and removes the ineffective iframe sandbox configuration.

## Fixed

- Browser proxy now honors `X-Forwarded-Proto: https` when Caddy terminates TLS.
- Rewritten redirects remain `https://wa...os.juloc.de` instead of falling back to insecure HTTP.
- Proxied cookies keep the `Secure` attribute when the public request is HTTPS.
- Upstreams receive the public forwarded protocol rather than JulOS's internal container HTTP scheme.
- Removed the Browser iframe sandbox that combined `allow-scripts` and `allow-same-origin` and
  produced browser warnings while still allowing full script/origin behavior.
