# JulOS 0.4.0-beta.42

Released 2026-09-12.

## Summary

Forty-second JulOS beta. Improves the Remote application for RDP use on phones, tablets and desktop,
with mobile-first controls, Gboard/IME input handling and configurable display behavior.

## Changed

- Connected Remote sessions now prioritize the remote display and keep controls in a small overlay
  instead of permanently consuming application space.
- Direct touch and trackpad input modes are available, including long-press or two-finger right click,
  two-finger scrolling and an explicit right-mouse-button control.
- Gboard, IME composition, pasted text and Unicode input use one bounded input path with duplicate-input
  regression coverage.
- Common Windows controls are available from the Remote overlay, including Ctrl, Alt, Shift, Win, Tab,
  Escape and Ctrl+Alt+Del.
- Remote display settings now include automatic/native/fixed/custom resolutions, local scaling and
  configurable remote-cursor visibility.
- RDP resize behavior is configurable per saved connection: dynamic `display-update`, explicit
  reconnect, or fixed remote resolution with local scaling only.
- The Guacamole RDP compatibility/default resize policy now uses `display-update` instead of forcing a
  reconnect for ordinary viewport changes.
- Remote package updated from `1.0.4` to `1.0.5`.

## Validation

- Full repository CI passed before merge, including .NET tests, Remote frontend tests, container builds
  and Clean-Tree validation.
- Real rendered Windows RDP and Android touch/keyboard acceptance remains a separate deployed beta
  validation gate and is not inferred from CI.
