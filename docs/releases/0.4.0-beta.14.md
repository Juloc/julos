# JulOS 0.4.0-beta.14

Fourteenth JulOS beta. This is a server-only diagnostic prerelease for the Remote display WebSocket path.

## Changed

- Remote display provider connection failures now write a warning with the resolved provider endpoint, the full .NET exception chain and whether the HTTP request cancellation token had already been cancelled.
- Browser-facing failures remain unchanged and still return the stable `remote.display_provider_unavailable` 502 response without exposing internal network details.
- The three official packages remain at `1.0.3`; package and runtime images are unchanged.

## Deployment

The server image for this prerelease is:

`ghcr.io/juloc/julos-server:0.4.0-beta.14`

Existing data and keys remain compatible. Preserve `JULOS_PRIMARY_KEY`, `JULOS_RUNTIME_MANAGER_KEY` and `JULOS_REMOTE_PROVIDER_CALLBACK_KEY` when upgrading.

Runtime images remain digest-pinned and unchanged:

- Browser runtime: `ghcr.io/juloc/julos-browser-runtime@sha256:933a2a8b7bc260560d0c2459ca8aa102596ab282bb094eb690c5ecf767302a8a`
- Remote provider: `ghcr.io/juloc/julos-remote-provider@sha256:e9c9d61adb82e56370a5fdaa76344dab686b4afd90a2ce41fc82cfe3a510b643`

## Validation focus

- inspect the `julos` container warning for the exact provider endpoint and `WebSocketException`/inner exception
