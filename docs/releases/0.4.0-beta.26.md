# JulOS 0.4.0-beta.26

Released 2026-09-01.

## Summary

Twenty-sixth JulOS beta. It reworks the mobile desktop shell so it behaves like a touch OS instead of a shrunken desktop. The taskbar becomes an iPad-OS-style dock, the shell chrome is much more compact, and the local web-app header adapts for mobile. This is a frontend-only change; the server image is rebuilt to carry the new Desktop bundle. No package, runtime or provider images change.

## Upgrade

| Question | Answer |
|---|---|
| Minimum previous version | `0.4.0-beta.25` |
| Database migration required | no |
| Downtime expected | brief restart |
| Safe mode required | no |

Pull the new server image and redeploy. Hard-refresh the browser (or reopen the installed PWA) once so the updated shell assets load.

## Changed

- **The mobile taskbar is now an iPad-OS-style dock.** On phone-class viewports (`data-interface-viewport="mobile"`) the taskbar is a centred, content-width floating pill with a full border and a hairline divider before the status cluster, instead of a full-bleed bottom bar. It stays icon-only: the search field, version label and clock are hidden, while the running-app window-count badge is kept.
- **Mobile chrome is smaller across the board.** Control height drops 48→40, taskbar height 70→56, window titlebar 48→40 and window controls 50→42, so app windows keep more of the screen.
- **The settings button stays reachable on mobile.** The user/settings button gained a gear glyph so it remains tappable once its name label is hidden, and the legacy width-based rules no longer hide the settings, agent-status and notification buttons on narrow screens (which had left settings unreachable on phones).
- **The local web-app header adapts for mobile.** The header is slimmed and its address field is set to 16px so mobile Safari stops auto-zooming the viewport and mis-scaling the embedded page; the iframe is guaranteed to fill the area below the header.

## Known limitations

- The mobile dock floats over app content the way an iPad dock does; per-app dock auto-hide and a matching content inset are not yet implemented.
- Deployed rendered-display acceptance for RDP, VNC, SSH and Browser against the pinned provider image remains open (issues #37 / #41 / #43 / #45).
- Remaining WEB-001 work: body/reference rewriting, the runtime shim, Agent-tunnel reachability, server-side credential injection and the `auto` streamed fallback.
- Appearance personalization: a user-selectable accent, appearance presets and wallpaper/density controls are deferred (see DESK-016).
