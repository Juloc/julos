# Desktop UX release gate

JulOS 1.0 requires completion of `docs/DESKTOP_UX_COMPLETION.md` before the Desktop foundation is considered release-ready.

The gate covers first-run setup, production shell composition, Windows/macOS-friendly desktop interactions, taskbar/launcher behavior, keyboard and touch input, appearance preferences and a clean-install acceptance path.

This gate is intentionally placed before the remaining package-heavy 1.0 phases so technical package completion cannot hide an incomplete desktop experience.
